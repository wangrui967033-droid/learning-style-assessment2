# 学习风格测评 V2 内测发布检查表

> 使用方式：每个版本发布前逐项填写“通过/不通过/不适用”、证据链接、检查人和日期。带 **阻断** 的项目未通过时不得发布。空白项等同于未通过。

## 1. 版本与产品边界

- [ ] **阻断** 页面和报告明确标注“发展版”或“试测版”，未使用“正式版”“权威诊断”等表述。
- [ ] 题库版本、计分版本、报告版本和应用版本均已记录，且与本批数据一致。
- [ ] 本次题目或算法变更均有变更说明；重大题意修改已经重新进行认知访谈。
- [ ] **阻断** 产品只解释当前学习入口偏好，不声称测量能力、智力、人格、心理健康或固定学习类型。
- [ ] **阻断** 学习科学策略不参与视觉、听觉、读写、动觉偏好得分。
- [ ] **阻断** 16 个二级机制只输出定性证据，没有百分比、精确排名或固定“主要机制”结论。

## 2. 题量、选项与基础信息

- [ ] **阻断** 普通路径恰好完成 42 道题：32 道偏好题 + 10 道学习科学题。
- [ ] **阻断** 仅当最高两类指数差距小于 10 分时追加 4 道校准题；校准路径恰好 46 道。
- [ ] **阻断** 动态校准最多一轮，校准作答不改写四类原始偏好指数。
- [ ] 每个固定页面显示 3 道题，每个校准页面显示 2 道题；进度不显示测量维度。
- [ ] **阻断** 分数区间包含“550至600、600以上”。
- [ ] **阻断** 外语支持“英语、日语”，唯一目标学科支持“日语”。
- [ ] **阻断** 只允许选择一门目标学科；英语/日语目标学科与所选外语一致。
- [ ] **阻断** 页面、请求、数据库有效字段和 CSV 均不包含 `examSubjects` 或“实际考试科目”。

## 3. 匿名与隐私

- [ ] **阻断** 不采集姓名、手机号、学校、身份证明或 IP 地址。
- [ ] **阻断** 会话 ID 不可预测，不使用连续数字作为公开报告地址。
- [ ] 匿名编号格式和生成规则已验证，不包含个人信息。
- [ ] 服务端拒绝题库之外的题目、选项和答案类型。
- [ ] 前端仅保存恢复作答所需的匿名草稿；提交成功后清理本地答案。
- [ ] SQLite、备份、CSV 和管理令牌均已被 Git 忽略，且不在 Web 静态目录。

## 4. 专家审查门槛

- [ ] 已完成 3 至 5 名专家独立审查，专业背景覆盖测量、学习/认知科学和高中教学。
- [ ] 每道核心题已检查单一构念、场景真实、抽象措辞、社会赞许、反向清晰、学科中立和维度匹配。
- [ ] “单一构念、场景真实、表达具体、维度匹配”的单题内容效度比例均达到 0.78。
- [ ] **阻断** 所有能力化、人格化、明显正确答案和生活兴趣题已删除或改写。
- [ ] **阻断** 被 2 名及以上专家判断为易误解的反向题已处理。
- [ ] 核心题蓝图仍满足四类偏好、四个过程、学科/生活场景、反向题和二级机制平衡。

## 5. 认知访谈门槛

- [ ] 已完成 12 至 20 名目标学生访谈，并覆盖不同年级、专业方向、分数区间和英语/日语。
- [ ] 每道核心题至少由 3 名学生口述理解；反向题、生活题和校准题已重点覆盖。
- [ ] 每道核心题至少 80% 的访谈者按预设构念理解。
- [ ] **阻断** 2 名及以上学生出现的同类关键误解已处理。
- [ ] **阻断** 所有反向方向误解、双重否定和生活场景人格化理解已处理。
- [ ] 至少 80% 的学生无需解释即可说清主要结论，并知道结果不是能力标签。
- [ ] 至少 70% 的学生无需解释即可说清目标学科优先行动、产出和完成标准。
- [ ] 报告符合程度 4 至 5 分比例达到 70%；所有 1 至 2 分反馈已逐条分析。

## 6. 80-150 人预测试统计门槛

- [ ] 已有 80 至 150 名目标用户参加预测试，并区分全启动、完整和有效反馈样本。
- [ ] 排除规则在查看结果前记录；未为了提高指标而事后删除正常样本。
- [ ] 已输出每题 1 至 5 分分布、均值、标准差、缺失率和作答时间。
- [ ] 分布集中、标准差低于 0.70、无人选择选项的题目均已复核并记录决策。
- [ ] **阻断** 所有偏好题 CITC 均非负。
- [ ] CITC 低于 0.30 的题目均已进入复核；低于 0.20 的题目已替换、重写或有书面暂留理由。
- [ ] 四个主维度均已计算 Cronbach's α 和 McDonald's ω。
- [ ] α/ω 均达到 0.70，或仅存在有书面修订计划的 0.65 至 0.69 条件项。
- [ ] **阻断** 不存在 α/ω 低于 0.65 或二者差异超过 0.10 的未解决主维度。
- [ ] **阻断** 反向题无负 CITC、计分方向错误或重复认知误解。
- [ ] **阻断** 未把二级机制的两题结果解释为精确分量表；机制百分比未进入报告。

## 7. 完成、校准与符合度门槛

- [ ] 总完成率不低于 85%。
- [ ] 完整样本完成时长中位数接近 8 至 10 分钟，且不超过 12 分钟。
- [ ] 完成时长第 90 百分位数不高于 15 分钟。
- [ ] 3 分钟内完成比例不高于 10%，并已完成敏感性分析。
- [ ] 异常退出页面已检查题目、交互和加载问题。
- [ ] 校准完成率不低于 90%。
- [ ] 触发率低于 10% 或高于 45% 时已复核核心分布与阈值。
- [ ] 2:2 超过触发样本 50% 时已复核校准题区分度。
- [ ] 4:0/3:1 中校准胜出与校准前第一偏好一致率低于 60% 时已完成专项复核。
- [ ] 校准左右位置选择差异未超过 15 个百分点，或已排除位置偏差。
- [ ] 报告符合程度 4 至 5 分比例不低于 70%，1 至 2 分比例不高于 15%。
- [ ] **阻断** 没有未处理的“建议与目标学科无关”“看不懂下一步”“被贴标签”反馈。
